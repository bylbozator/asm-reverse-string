# Перевод строки в обратном порядке (TASM)

**Ассемблерная программа: реверс введённой строки с защитой от переполнения буфера.**

[![x86](https://img.shields.io/badge/x86-16bit-00599C?logo=intel&logoColor=white)](https://en.wikipedia.org/wiki/X86_assembly_language)

</div>

Учебная лабораторная работа по низкоуровневому программированию: чтение строки
через DOS-прерывание `int 21h`, посимвольная инверсия «на месте» и вывод результата.

## Что делает

- Принимает строку длиной до **200 символов**.
- Контролирует переполнение входного буфера (`0Ah` + проверка длины).
- Разворачивает строку с двух концов через указатели `SI`/`DI` (обмен `xchg`).
- Выводит модифицированную строку и сообщение о завершении.

## Как собирать

```bash
tasm one.asm
tlink one.obj
one.exe
```

## Пример работы

```
Input a string (maximum 200 characters): hello world
Modified string: dlrow olleh
End of input.
```

## Детали реализации

- Сегмент данных с нулевой инициализацией буфера (`.data`).
- Функция `reverse_string` — переставляет символы до пересечения указателей.
- Обработка ошибки `Error: buffer overflow` при превышении лимита.
- Завершение через `int 21h` (`4C00h`).
